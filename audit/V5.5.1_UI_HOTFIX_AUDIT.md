# Licora v5.5.1 UI Hotfix Audit

## Frozen source authority

- Official source base: Licora v5.5.0
- Official v5.5.0 tree: `7bcbf921940cc5eb9c2f1d21971394063ad7e82f`
- Target: v5.5.1
- Scope: Settings shortcut distribution, Settings lower-grid composition, collapsible Settings submenu, professional About page.

## Confirmed root causes

1. **Shortcut distribution:** `ui-shortcuts` used a simple flex row with intrinsic-width buttons, leaving unused space across the Settings page.
2. **Cron blank-space composition:** Settings used a two-column CSS grid while `ui-span-2` was only defined under `.ui-form-grid`; therefore `API & Integration` did not span the intended width and forced the short Cron card to stretch beside the much taller API panel.
3. **Sidebar submenu:** child navigation was always rendered as `display:grid` and `sidebar.js` contained no submenu state controller.
4. **About page:** a settings-style definition-list layout was reused for a product overview, producing an unbalanced sparse page with no capability hierarchy.

## Corrective implementation

- Equal-width responsive Settings shortcut grid.
- Dedicated `ui-settings-detail-grid` with a right-side `ui-settings-stack` for Cron + API v2 Signing.
- Separate Settings navigation link and accessible chevron toggle using `aria-expanded`, `aria-controls`, server-side active-child expansion, and client-side collapse/expand.
- Shared product/About components in the central component stylesheet; no page-specific stylesheet or inline `<style>` block.
- About content is limited to project capabilities and company information already documented in the repository.

## Frozen boundaries

No API v1/v2 protocol, cryptography, license/device behavior, database schema, cron semantics, authentication, authorization, updater state machine, signing, backup or rollback implementation is changed.
