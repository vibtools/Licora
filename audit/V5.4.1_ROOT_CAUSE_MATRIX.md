# Licora v5.4.1 Root Cause Matrix

| Severity | Area | Root cause | Observed/possible impact | Corrective action |
|---|---|---|---|---|
| P0 | Updater browser | JS expected `update-log-title`; HTML rendered `licora-update-log-title` | Real job persisted but browser stopped at `fetch_manifest / 1%` | Align DOM ID; validate required DOM; execute browser-runtime test |
| P1 | Updater frontend state | Any non-null `state.job` treated as active | Terminal job could block a later same-page preflight | `jobIsActive()` only for `running`/`rollback_running` |
| P2 | UI consistency | Native `confirm()` bypassed shared component system | Browser/platform dark dialog inside light UI | Reusable Licora Light confirmation modal |
| P1 | HTTP transport | PHP-stream fallback buffered entire package | Memory exhaustion on cPanel/shared hosts without cURL | Chunked bounded stream-to-disk fallback |
| P1 | ZIP validation | Directory entries skipped before path/type checks | Traversal/type validation gap | Validate all paths/types before extraction; reject collisions/symlinks/specials |
| P1 | Backup integrity | Several writes/copies lacked verified completion | Truncated backup could be treated as valid | Checked writes + persisted/verified source hashes |
| P1 | Rollback integrity | Restore trusted retained files without persistent v5.4.1 hash inventory | Corrupt backup could be copied during future rollback | Verify hashes; backward-compatible fallback for legacy in-flight jobs |
| P1 | Manifest pipeline | Builder/runtime rejection rules differed | CI could sign an artifact installed runtime rejects | Mirror protected/delete/migration/collision rules |
| P1 | Release workflow | Signature verified, exact package not run through runtime archive verifier | Packaging/runtime incompatibility could reach Release | Exact signed artifact runtime verification before publish |
| P3 | Test coverage | UI tests were marker/syntax based | DOM mismatch passed local/CI tests | DOM graph test + Node runtime fixture + builder contract test |
| P3 | Release verification self-hosting | Newly added builder adversarial test initially assumed `.git` existed | Exact `git archive` package verification failed before artifact build | Test now creates its own disposable Git fixture and passes inside exported source |
