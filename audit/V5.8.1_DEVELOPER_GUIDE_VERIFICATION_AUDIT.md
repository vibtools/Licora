## Findings

### RC-581-001 — CI candidate package/manifest version mismatch

The v5.8.0 candidate CI packaged `Licora-5.8.0.zip` but invoked `build-update-manifest.py --version 5.7.1`. The manifest builder enforces package/spec/version coherence, so remote candidate-artifact creation would fail. v5.8.1 aligns package, release specification and manifest-builder version.

### RC-581-002 — Dashboard device glyph unavailable

The Dashboard used `bi-devices` while the existing Bootstrap Icons 1.8.1 dependency does not provide that icon. Only the two Dashboard occurrences are changed to the available `bi-laptop`; Dashboard data/behavior is untouched.

### Chrome download complaint

No `chrome.exe`, Chrome installer/download URL, browser-launch shell/process implementation or Chrome downloader exists in the uploaded Licora PHP source or reviewed repository history. Therefore no evidence-backed repository fix is possible; adding a downloader would be a new speculative feature and is intentionally not done. The source guard is extended to the Developer Guide surface.
